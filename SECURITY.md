# 🛡️ Security Policy

## Supported Versions

We provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Yes             |
| < 1.0   | ❌ No              |

## Reporting a Vulnerability

We take the security of our travelers' data very seriously. If you discover a vulnerability, please report it via the following process:

1. **Do not disclose publicly**: Please report vulnerabilities privately.
2. **Email us**: Send a detailed report to `security@malangtour.com`.
3. **Response time**: You will receive an initial response within 48 hours.
4. **Resolution**: We aim to resolve critical issues within 7 days.

### Prohibited Actions
- Accessing or attempting to access data that does not belong to you.
- Executing Denial of Service (DoS) attacks.
- Using automated scanners that generate excessive traffic.

Thank you for helping keep MalangTour safe!
